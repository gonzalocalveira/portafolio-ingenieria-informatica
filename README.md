# 📚 Portfolio – Ingeniería en Informática

Repositorio que reúne proyectos académicos y personales desarrollados durante la carrera de Ingeniería en Informática.

El objetivo de este espacio es centralizar implementaciones realizadas en distintos lenguajes y tecnologías, aplicando buenas prácticas de desarrollo, modelado de datos y arquitectura de software.

---

## 🚀 Tecnologías utilizadas

A lo largo de los proyectos incluidos se trabajan tecnologías como:

- Java
- Python
- JavaScript
- SQL
- MongoDB
- Cassandra
- Redis
- Docker
- Arquitectura en capas
- Persistencia poliglota

*(El repositorio se encuentra en constante crecimiento.)*

---

## 📂 Proyectos incluidos

### 🎓 EduGrade
Sistema académico desarrollado como proyecto de 3er año.

Incluye:
- Backend estructurado en capas
- Gestión de estudiantes, profesores y calificaciones
- Arquitectura organizada por servicios
- Integración de múltiples tecnologías de persistencia
- Documentación técnica incluida

---

## 🎯 Objetivo del repositorio

- Consolidar conocimientos adquiridos durante la carrera.
- Aplicar conceptos de bases de datos relacionales y NoSQL.
- Implementar arquitecturas mantenibles y escalables.
- Documentar decisiones técnicas y modelado de datos.
